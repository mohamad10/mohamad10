# سایت رزومه تیم برنامه‌نویسی

سایت معرفی تیم، تخصص‌ها، اعضا (با سطح تخصص و مهارت‌ها) و نمونه‌کارها. راست‌چین، تم روشن/تاریک، واکنش‌گرا و بدون نیاز به سرور.

## اجرا
فایل `index.html` را در مرورگر باز کنید، یا پوشه را روی هر هاست استاتیک (مثل GitHub Pages) قرار دهید.

## مدیریت محتوا
1. به `admin.html` بروید (لینک «پنل مدیریت» در پایین سایت). در اولین ورود رمز تعیین می‌کنید.
2. اطلاعات تیم، خدمات، اعضا (عکس، سطح، سابقه، مهارت‌ها با درصد، تحصیلات، لینک‌ها) و پروژه‌ها را ویرایش کنید؛ همه‌چیز خودکار ذخیره می‌شود.
3. برای انتشار عمومی: در «پشتیبان‌گیری و تنظیمات» فایل `data.js` را دانلود و جایگزین `assets/data.js` کنید.

> تغییرات پنل در مرورگر شما ذخیره می‌شوند و رمز پنل سمت کاربر است؛ داده‌ی عمومی سایت همان `assets/data.js` است.

## ساختار
- `index.html`, `assets/app.js`, `assets/style.css` — سایت
- `admin.html`, `assets/admin.js`, `assets/admin.css` — پنل مدیریت
- `assets/data.js` — محتوای سایت
